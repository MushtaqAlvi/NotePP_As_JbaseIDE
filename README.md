# 🚀 Notepad++ JBC & JShell Configuration for T24 (JBase)

Make coding **JBC (InfoBasic)** and **JShell** programs smoother, faster, and visually appealing with **syntax highlighting** and **auto-completion** in Notepad++!  

---

## 🔹 Features

- **Syntax Highlighting** for JBC & JShell programs  
- **Auto-completion** for faster coding  
- Supports `.b` files (JBC programs)  
- Easy 3-step setup — no complex installation required  

---

## 📦 Included Files

| File Name       | Purpose |
|-----------------|---------|
| `Jbc_udl.xml`   | User Defined Language for JBC syntax highlighting |
| `Jsh_udl.xml`   | User Defined Language for JShell syntax highlighting |
| `jbc.xml`       | Auto-completion configuration for JBC |

💡 **Note:** These files are embedded in this repo — just copy or download them.  

---

## ⚡ Setup Guide

### Step 1: Import User Defined Languages (UDL)

1. Open **Notepad++**  
2. Go to `Language → User Defined Language → Define your language`  
3. Click **Import** → select `Jbc_udl.xml` & `Jsh_udl.xml`  


---

### Step 2: Enable Auto-Completion

1. Copy `jbc.xml`  
2. Paste it into the Notepad++ **autoCompletion** folder:

C:\Program Files\Notepad++\autoCompletion


3. Done! Auto-completion is now active ✅

---

### Step 3: Start Coding!

- Open any `.b` file (JBC program)  
- Notepad++ automatically applies syntax highlighting  
- Use auto-completion to speed up coding
